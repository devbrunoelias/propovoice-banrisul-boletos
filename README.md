# Propovoice Banrisul Boletos

## Alterações da V10
1. Consolidada a documentação de segurança dos PDFs.
2. Mantido o download por endpoint protegido e bloqueio da URL direta.
3. Iniciado o planejamento para suporte a múltiplas empresas e beneficiários.
4. Definidos requisitos preliminares para vincular cada boleto à empresa responsável.
5. Planejada a adaptação da API, consulta manual, WP-Cron, webhook e homologação para o cenário multiempresa.
6. O suporte multiempresa ainda não deve ser considerado concluído nesta versão.
