### Configuração dos logotipos que aparecem no LINK Público que vai pro cliente

Por motivos de privacidade e identidade visual, os logotipos utilizados em produção não estão incluídos neste repositório.

Antes de utilizar o portal público de cobranças, crie a seguinte estrutura dentro do plugin:

```text
assets/
└── images/
    ├── logo-catania-studio.png (Aqui utilize um logo branco com fundo transparente). - LOGO PARA CABEÇALHO
    └── logo-catania-spweb-colorido.png (Aqui utilize um logo colorido com fundo transparente). - LOGO PARA RODAPÉ
```
